# 数据备份与换设备迁移说明

## 数据存在哪里

物品、日志、分类、照片和设置全部保存在当前设备、当前浏览器、当前网址的本地数据库中。应用没有服务器账号，也没有自动同步。

同一部手机上的不同浏览器、电脑与手机、不同域名或端口，都可能拥有互不相通的数据。安装后的 PWA 与普通浏览器是否共享数据取决于系统，迁移前请实际确认。

## 日常备份

1. 进入“我的 → 备份与迁移”。
2. 选择“下载完整 ZIP 备份”。文件名形如 `personal-items-backup-20261103-164400.zip`。
3. 在下载目录确认文件确实存在，再点击“已确认文件保存”。如果取消了下载，请取消确认。
4. 将文件另存到可靠的位置，例如自己的外置磁盘或可信的个人文件空间。应用本身不会自动上传。

备份包含所有五张表、原有分类和设置、回收站中的物品与其照片和日志，以及每个文件的 SHA-256 校验值。它没有加密，别人获得文件后可能看到价格、渠道和照片。

“最近确认备份”只表示你确认已生成并发起下载，不代表云端存在副本。导出包保存的是导出时的设置快照，因此将它恢复后，该设置中的上次备份时间可能早于本次下载，这是正常现象。

## 换设备

1. 在旧设备完成完整备份，并检查 ZIP 文件。
2. 将文件传输到新设备。
3. 在新设备打开应用，进入“备份与迁移”，选择 ZIP。
4. 应用检查版本、文件清单、大小、SHA-256、图片类型、数据字段、分类与日志关联。失败时不会修改新设备的数据。
5. 检查预览显示的物品、日志、照片数量和生成时间。
6. 先下载并确认新设备当前数据的安全备份；确实不需要保留时，可单独确认跳过。
7. 点击“覆盖恢复此备份”，再次确认替换全部数据。
8. 恢复完成后，检查照片、使用记录和统计。确认正常后再处理旧设备。

恢复不会合并两份记录。若两个设备都进行了新的录入，需要自行决定以哪份完整数据为准。

## 常见情况

| 情况                   | 处理                                                       |
| ---------------------- | ---------------------------------------------------------- |
| 文件被修改或下载不完整 | 原数据不变；使用另一个完整备份或重新导出                   |
| 不支持的备份版本       | 使用对应版本的应用；当前版本不会静默跳过字段               |
| 超过 50 MB             | 先减少不必要的图片、单张图片体积，再导出；桌面也遵守此上限 |
| 物品没有价格           | 保持未知，不计入金额合计，单位成本显示破折号               |
| 浏览器清空数据         | 只能从已有完整备份恢复                                     |
| 只有 CSV               | CSV 只供外部分析，没有照片，不能完整恢复                   |
| 离线首次打不开         | 必须先在线加载生产版本并完成缓存                           |
| 换网址后列表为空       | 新网址使用独立数据库，请从旧网址导出后迁移                 |

不要通过手动编辑 ZIP 修复业务数据。先正常恢复，再在应用里更正物品或使用记录，最后重新导出。
